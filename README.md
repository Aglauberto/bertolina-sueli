# Análise de Perfil Comportamental Big Five | Bertolina Sueli

Landing page de alta conversão para o serviço de Análise de Perfil Comportamental baseada no modelo científico Big Five, por Bertolina Sueli (Advogada, Mediadora Judicial e Analista Comportamental).

## 🚀 Tecnologias

- HTML5 Semântico
- Tailwind CSS
- Vanilla JavaScript (FAQ accordion, data dinâmica, efeitos de scroll)
- Otimização completa para mobile e desktop
